# 卫君后台管理系统

基于 Vue 3、Element Plus、Vue Router、Pinia 和 Vite 实现的后台管理框架。

## 功能

- Pinia 管理登录用户、角色和权限判断。
- 路由通过 `meta.roles` 控制可访问角色，全局路由守卫拦截越权访问。
- 侧边栏根据当前角色动态生成菜单和子菜单。
- 首页包含关键指标卡、省份柱状图、疾病分类占比、月度趋势和医院分类统计。
- 服务包订单管理包含关键词、省份、状态、日期范围筛选、分页、序号列、状态标签、查看、编辑、删除。
- 新增/编辑弹窗包含输入框、下拉选择、单选框、日期选择器、文本域、提交和取消。

## 演示账号

| 角色 | 用户名 | 密码 | 权限范围 |
| --- | --- | --- | --- |
| 系统管理员 | `admin` | `admin123` | 全部菜单 |
| 医生 | `doctor` | `doctor123` | 首页、医生管理、健康咨询、订单管理 |
| 客服人员 | `service` | `service123` | 首页、排班/照护/陪诊管理、健康咨询、服务订单 |

## 启动

```bash
npm install
npm run dev
```

构建生产包：

```bash
npm run build
```

当前 Windows 环境如果禁止 Node 调起 `cmd.exe`，脚本已通过 Vite 的 `--configLoader native` 绕过配置预加载阶段的兼容探测。
