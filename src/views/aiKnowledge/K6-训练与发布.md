- 右侧按钮 `开始训练`

## 4. 训练进度

- 点击后进入训练态：显示 `训练中` + `{progress}%` + 进度条（`el-progress`，不显示自带文字）
- 轮询 `getKbTrainJobById(jobId)`，间隔 2000ms
- 状态分支：
  - `PENDING` / `RUNNING` → 更新 progress，继续轮询
  - `COMPLETED` → 停止轮询，`ElMessage.success('训练完成，已生成新版本')`，刷新版本列表
  - `FAILED` → 停止，`ElMessage.error(message || '训练失败')`
- 训练中「开始训练」不可点；组件卸载/切 Tab 清理定时器
- 不要伪造进度动画，进度值只来自 `progress`

## 5. 版本历史

- 标题 `版本历史`，副标题 `发布后立即生效，可回滚到历史版本`
- 每行：时钟图标 + `{version} · {qaCount} 条知识 · {publishedAt | trainedAt}`，第二行 `status` 中文
- 状态：`TRAINING` 训练中 / `COMPLETED` 已完成 / `PUBLISHED` 已发布 / `ROLLED_BACK` 已回滚
- 行尾按钮规则：
  - 当前线上版本（`PUBLISHED` 且发布时间最新）→ 绿标「当前发布版本」，无按钮
  - 其他 `COMPLETED` → 「发布此版本」
  - `TRAINING` → 无按钮
- 排序：`publishedAt` 倒序，空值排后
