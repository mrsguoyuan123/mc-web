## 2. 接口

| 用途 | 函数 | 参数 |
| --- | --- | --- |
| 三张统计卡 | `getKbOverview()` | 无 |
| 最新未解决 3 条 | `getKbUnresolvedPage({ status: 'PENDING', page: 1, pageSize: 3 })` | — |
| 发布状态 | `getKbVersions()` | 无 |
| 近 7 天趋势 | `getKbHitTrend({ days: 7 })` | **占位，见 G1** |

## 3. 字段映射

`getKbOverview` 返回：

| 展示 | 字段 | 规则 |
| --- | --- | --- |
| 知识条目总数 | `total` | 大数字；缺失显示「接口未提供」 |
| 副行 | `published` / `draft` | `已发布 X · 草稿 Y` |
| 近 30 天命中率 | `hitRate30d` | 按 0~100 拼 `%`；0~1 小数自动 ×100 |
| 命中率环比 | `hitRateDelta` | **占位（G2）**，缺失时整行隐藏，禁止写死 `+3.2%` |
| 待处理未解决 | `unresolvedPending` | 橙色卡，点击跳转 |
| Tab 角标 | `unresolvedPending` | 由 `index.vue` 取，>0 才显示 |

## 4. 布局

1. 三卡一行：知识条目总数 / 近 30 天命中率 / 待处理未解决问题（第三张暖色底 + 「前往处理 →」）
2. 整宽面板「近 7 天命中趋势」，副标题「智能客服回答命中与未命中问题数量（单位：条）」
3. 两栏：左「最新未解决问题」（3 条，来源科室 · 时间 + 「处理」按钮）、右「发布状态」（3 个版本，当前版本绿标、历史版本灰标）

## 5. 关键交互

- 卡片或「前往处理 →」点击：`emit('go-unresolved', '')` → 父组件切到未解决问题 Tab
- 单条「处理」：`emit('go-unresolved', row.id)` → 切 Tab 并高亮该行
- 版本「当前」判定：`status === 'PUBLISHED'` 且 `publishedAt` 最新的一条
- 版本行展示 `version · qaCount 条知识`，时间优先 `publishedAt`，为空取 `trainedAt`

## 6. 缺口

| 编号 | 缺口 | 处理 |
| --- | --- | --- |
| G1 | 近 7 天命中/未命中趋势无端点 | 占位 `getKbHitTrend({days:7})`，期望 `[{date, hit, miss}]`；接口失败时趋势区显示灰底空态 + 红色「接口未提供」，**不画假柱** |
| G2 | 命中率环比无字段 | 读 `hitRateDelta`，缺失隐藏副行 |

## 7. 验收

1. 三卡数字来自 overview，缺失显示「接口未提供」而非 `0` 或 `--`
2. 趋势区没有接口时是空态，不是随机柱状图
3. 「处理」点击后 Tab 切到未解决问题并高亮对应行
4. 当前版本只有一个绿标，历史版本不重复标记
