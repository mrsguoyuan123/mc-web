# K5 · 检索测试 Tab

> 通用约定见 K1 开头：无 TS、雪花 ID 字符串、缺失显示「接口未提供」、utils 走 `@/utils/index.js`、接口走 `../../../api/index.js`。

## 1. 文件

`src/views/aiKnowledge/components/SearchTestTab.vue`

## 2. 接口

| 用途 | 函数 |
| --- | --- |
| 检索 | `testKbSearch({ query, topK: 5 })` |

返回 `KbSearchHit[]`：`{ entry: KbEntry, score }`，**空数组即未命中**。

## 3. 布局

单个面板：

- 标题行：图标 + `检索测试`
- 副标题固定文案：`模拟用户提问，验证智能客服能否从知识库中命中正确答案。`
- 输入行：输入框 placeholder `例如：怀孕初期应该注意什么？` + 右侧「开始测试」按钮
- 结果区：命中时列命中条目，未命中时显示橙色提示块

## 4. 命中结果

每条命中卡展示：

| 展示 | 字段 |
| --- | --- |
| 匹配分 | `score`（百分比，绿色小字） |
| 科室 | `entry.department`（tag） |
| 标准问 | `entry.question`（加粗） |
| 标准答案 | `entry.answer`（灰色正文，完整不省略） |

按 `score` 倒序展示，最多 5 条。

## 5. 未命中

- 暖橙底块，居中
- 主文案：`未命中任何知识`
- 副文案：`建议前往「未解决问题」新增这条问答，或补充文档知识。`
- 不自动创建任何记录（手动新增未解决的接口缺，见 G7）

## 6. 交互规则

- 输入为空时「开始测试」禁用；回车等价点击
- 请求中按钮 loading，结果区 loading
- 每次测试先清空上一次结果，避免旧结果残留
- 请求失败按「未命中」处理？**不行**。失败时结果区显示「接口未提供」+ 不显示未命中提示，区分"没命中"和"没请求到"
- 未命中/失败都不弹全局 message，只在结果区呈现

## 7. 缺口

| 编号 | 缺口 | 处理 |
| --- | --- | --- |
| G7 | 未命中后无法一键「新增这条问答」到未解决池（无 `POST /kb/unresolved`） | 本页只做提示文案，不放置会失败的按钮；若后端补齐再接入口 |

## 8. 验收

1. 输入空时按钮禁用
2. 命中时展示 score + 科室 + 标准问 + 答案，条目数量与接口返回一致
3. 返回空数组显示未命中块，文案逐字一致
4. 请求异常时显示「接口未提供」，不误报「未命中」
