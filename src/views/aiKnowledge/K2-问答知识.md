## 4. 工具栏

- 搜索框 placeholder：`搜索标准问、相似问、答案或标签`，回车/清空触发查询，`keyword` 透传
- 科室下拉、状态下拉：**先禁用**并加 tooltip「后端待补筛选参数」，因为 `GET /kb/entries` 目前不收 `department`、`publishStatus`（G3）
- 右侧：下载导入模板、批量导入、新建问答

## 5. 新增 / 编辑弹窗（同一个 dialog）

- 标题：新增时「新增标准问答」，编辑时「编辑问答」
- 副标题：`标准问、相似问和标准答案将作为智能客服的训练数据。`
- 字段：科室*（下拉）、标准问*、相似问法（顿号/逗号分隔）、标准答案*（textarea 4 行）、标签（顿号/逗号分隔）、状态（草稿/已发布，默认草稿）
- 提交：`similarQuestionsJson`、`tagsJson` 都要 `JSON.stringify(按顿号逗号切分的数组)`
- 按钮：新增为「保存并进入草稿」，编辑为「保存修改」
- 校验：标准问、标准答案必填，不满足只提示不发请求

## 6. 详情弹窗

展示：`#id` + 科室、标准问（浅蓝底加粗）、相似问 tags、标准答案（灰底）、标签 tags + 状态标、底部三格「命中次数 / 点赞 / 点踩」（`hitCount` / `likeCount` / `dislikeCount`）。

## 7. 删除确认（文案逐字）

```js
await ElMessageBox.confirm(
  '删除后该知识将不再参与训练和检索，此操作不可恢复',
  '确认删除这条问答？',
  {
    type: 'warning',
    confirmButtonText: '删除',
    cancelButtonText: '取消',
    confirmButtonClass: 'el-button--danger'
  }
)
```

- 批量：标题换成 `确认删除选中的 N 条问答？`，正文不变
- 成功后「已删除」并刷新；当前页删空且 `page > 1` 时回退一页

## 8. 缺口

| 编号 | 缺口 | 处理 |
| --- | --- | --- |
| G3 | 列表缺 `department` / `publishStatus` / `tag` 筛选参数；keyword 是否覆盖答案/标签未定义 | 两个下拉禁用 + tooltip；**禁止前端本地过滤**，会破坏分页 |
| G4 | 「批量导入」设计是传文件，现有接口只收 JSON 数组 | 占位 `importKbEntriesFile`；兜底方案是前端按模板解析 CSV 后调 `importKbEntries` |
| G5 | 「下载导入模板」无端点 | 前端生成静态 CSV（列：科室,标准问,相似问,标准答案,标签,状态） |
