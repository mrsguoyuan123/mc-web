# 指令 D2：团队结构抽屉 + 医生编辑/职称维护弹窗

> 前置：D1 列表页骨架已落地。本步实现「团队结构」抽屉与医生编辑（含职称、上级医生维护）弹窗。
> **接口口径：doctor swagger 定稿。团队返回 `doctor/manager/children/grandchildren` 平铺四组；职称通过编辑医生 `PUT /doctors/{id}` 保存，无独立职称端点；上级医生走 `PUT /doctors/{id}/manager`。**
> 空值口径同 D1：缺失显示红色「接口未提供」，0 值正常显示。

## 一、复用与位置

- 团队结构抽屉：`src/views/doctorManage/components/DoctorTeamDrawer.vue`
- 编辑/职称弹窗：`src/views/doctorManage/components/DoctorEditDialog.vue`
- 接口从 `../../api/index.js` 导入；复用 D1 职称/状态枚举。

## 二、团队结构抽屉

### 头部
- 标题「团队结构」，副标题「{医生姓名} 的医疗团队」；右上角关闭；底部「关闭」按钮。

### 数据结构（`getDoctorTeamById(id)` → `GET /doctors/{id}/team`）
返回平铺四组，**不是递归树**，前端按关系拼接层级展示：

| 字段 | 含义 |
|---|---|
| `doctor` | 本人（DoctorView） |
| `manager` | 上级医生，无则空对象 |
| `children` | 直接下级数组（DoctorView[]） |
| `grandchildren` | 隔级下级数组（DoctorView[]） |

### 层级展示
- 顶层卡片：本人，姓名 + 职称标签；信息行「区域 / 医院 / 科室 / 电话 / 负责用户：N 人」。
- 有 `manager` 时，在本人卡片上方显示「上级医生」卡片（姓名、职称、信息行）。
- 「下级医生」分组（人形图标 + 标题）：遍历 `children`，每个直接下级一张卡片；其隔级下级在该下级卡片内通过 `grandchildren` 匹配归属后缩进嵌套展示（按 `managerId` 关联，匹配不到的隔级下级归到「其他下级」分组）。
- 卡片信息行字段：`areaName/hospitalName/departmentName/phone/patientCount`（缺名字段用 id 或「接口未提供」兜底）。
- 团队为空显示「暂无下级医生」；抽屉内长列表滚动。

## 三、编辑医生弹窗（含职称、上级医生）

### 触发
- 列表「编辑」打开；先 `getDoctorById(id)` 拉详情回显。
- 新建走 `createDoctor`；编辑走 `updateDoctorById(id, data)`。

### 表单字段（DoctorRequest / DoctorView）

| 字段 | 控件 | 必填 | 备注 |
|---|---|---|---|
| 姓名 `name` | 输入框 | 是 | |
| 职称 `title` | 下拉 | 是 | 主任医师/副主任医师/主治医师/住院医师 |
| 手机号 `phone` | 输入框 | 是 | 全局唯一 |
| 医院 `hospitalId` | 下拉/选择 | 是 | 字典接口；雪花 ID 字符串 |
| 科室 `departmentId` | 下拉/选择 | 是 | 随医院联动 |
| 院区 `areaId` | 下拉/选择 | 否 | |
| 性别 `gender` | 下拉 | 否 | |
| 上级医生 `managerId` | 下拉（`getDoctorOptions`） | 否 | 选择在职医生；展示 `managerName` |
| 专长 `specialty` | 输入框 | 否 | |
| 擅长领域 `expertise` | 多选标签 | 否 | 字符串数组 |
| 邮箱 `email` | 输入框 | 否 | |
| 个人简介 `introduction` | 文本域 | 否 | |
| 学历 `education` / 毕业院校 `graduateSchool` | 输入框 | 否 | |
| 从业年限 `workYears` | 数字 | 否 | |
| 医师资格证号 `certNumber` / 执业证号 `practiceNumber` | 输入框 | 否 | |
| 头像 `avatar` | 上传 | 否 | 地址经 `resolveFileUrl` 解析 |
| 启用状态 `status` | 开关 | 否 | 1 启用 / 0 停用 |

### 职称变更提示
- 职称下拉下方黄色提示条：「提示：职称层级关系为：主任医师 > 副主任医师 > 主治医师 > 住院医师」。

### 校验与保存
- 必填：`name / title / phone / hospitalId / departmentId`。
- 保存：新建 `createDoctor(data)` → `POST /doctors`；编辑 `updateDoctorById(id, data)` → `PUT /doctors/{id}`。
- 单独调整上级医生：`updateDoctorManagerById(id, managerId)` → `PUT /doctors/{id}/manager`，包装 `{ managerId }`。
- 保存成功关闭弹窗、刷新列表；失败 ApiError 消息提示，不清空表单。

## 四、本段接口对接

| 用途 | 函数 | 路径 / 方法 |
|---|---|---|
| 团队 | `getDoctorTeamById(id)` | `GET /doctors/{id}/team` |
| 医生详情 | `getDoctorById(id)` | `GET /doctors/{id}` |
| 录入医生 | `createDoctor(data)` | `POST /doctors` |
| 编辑医生 | `updateDoctorById(id, data)` | `PUT /doctors/{id}` |
| 设置上级 | `updateDoctorManagerById(id, managerId)` | `PUT /doctors/{id}/manager` |
| 在职医生下拉 | `getDoctorOptions(params)` | `GET /doctors/options` |
