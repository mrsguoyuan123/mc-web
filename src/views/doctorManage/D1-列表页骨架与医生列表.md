# 指令 D1：医生管理列表页骨架 + 统计卡 + 医生列表（DoctorManage.vue）

> 模块定位：与「用户管理仓」「角色管理」平级的人员管理模块（公司管理端医生库），管理医生职称、团队结构和用户绑定关系。
> **接口口径：doctor 模块 swagger 共 21 端点，本列表对接医生库管理侧端点（`/doctors` 系列）；医生本人端 `/doctor` 工作台不在本模块。**
> 空值口径：字段缺失（null/undefined/空串）显示红色「接口未提供」，0 值正常显示；复用 `../utils.js` 的 `isMissing` / `MISSING_TEXT`。

## 一、技术规范（强制）

- Vue3 `<script setup>` 组合式 API + Element Plus，**不要 TypeScript**。
- 接口从 `../../api/index.js` 导入；api 层按 doctor swagger 导出同名函数。
- 表格 `table-layout: fixed`；日期时间 `YYYY-MM-DD HH:mm`。
- 雪花 ID 已由封装层转字符串，路径/入参 id 一律按字符串传递。

## 三、页签：医生列表 / 用户绑定

- 「医生列表」本步实现；「用户绑定」在 D3 落地。

### 筛选区（对接 `getDoctorPage` 入参）
- 搜索框：占位「搜索医生姓名或专科...」，入参 `keyword`（姓名/手机号）。
- 下拉「全部医院」：入参 `hospitalId`。
- 下拉「全部科室」：入参 `departmentId`。
- 下拉「全部区域」：区域筛选（`areaId`，列表项含 `areaId`；若 swagger 查询参数未单列区域，先留位待后端补）。
- 可加职称/状态筛选（`title` / `doctorStatus`，见枚举）。
- 切换筛选/搜索防抖后刷新列表。

### 医生列表表格列（`DoctorView` 字段映射）

| 列 | 接口字段 | 展示规则 |
|---|---|---|
| 姓名 | `name` | 缺失显示红色「接口未提供」 |
| 职称 | `title` | 主任医师/副主任医师/主治医师/住院医师，挂标签（见职称枚举） |
| 区域 | `areaId` → 区域名 | 区域名若未返回，展示 `areaId` 或红色「接口未提供」 |
| 医院 | `hospitalId` → 医院名 | 同上；详情接口可补 `hospitalName` |
| 科室 | `departmentId` → 科室名 | 同上 |
| 电话 | `phone` | |
| 状态 | `doctorStatus` | ACTIVE 在职 / SUSPENDED 停诊 / RESIGNED 离职 / CANCELLED 注销 |
| 上级医生 | `managerName` | 无上级显示 `-` |
| 团队人数 | `teamSize` | 整数，后缀「人」 |
| 负责用户 | `patientCount` | 整数，后缀「人」 |
| 操作 | — | 见下 |

### 操作列（每行）
- 编辑：铅笔图标，打开编辑医生弹窗（对接 `getDoctorById` + `updateDoctorById`，后续分段）。
- 团队结构：人形图标，打开团队结构抽屉（D2）。
- 「变更状态」下拉：停诊 / 离职 / 注销（D3）。

## 四、枚举字典（对齐后端码值，集中放 utils 或本文件顶部）

### 职称 `title`（中文直传，非英文码值）
| 展示 | 值 |
|---|---|
| 主任医师 | `主任医师` |
| 副主任医师 | `副主任医师` |
| 主治医师 | `主治医师` |
| 住院医师 | `住院医师` |

> 设计稿标签「主诊/主治/住院」为简称展示；下拉与提交以 swagger 中文枚举为准。层级关系：主任医师 > 副主任医师 > 主治医师 > 住院医师。

### 执业状态 `doctorStatus`
| 码值 | 展示 | 标签样式 |
|---|---|---|
| `ACTIVE` | 在职 | 绿标签 |
| `SUSPENDED` | 停诊 | 灰/橙标签 |
| `RESIGNED` | 离职 | 橙/红标签 |
| `CANCELLED` | 注销 | 灰标签 + 置灰行 |

## 五、数据口径

- 分页参数：`page`（默认 1）、`pageSize`（默认 20，上限 100）；返回 `{ list, total, page, pageSize }`，用 `utils.toPage` 归一。
- 空列表显示「当前无医生」空态。
- 医生变更（保存/改状态/团队调整/绑定）后刷新列表与统计卡。

## 六、本步接口对接

| 用途 | 函数 | 路径 / 方法 |
|---|---|---|
| 医生分页列表 | `getDoctorPage(params)` | `GET /doctors`（keyword/hospitalId/departmentId/title/doctorStatus/page/pageSize） |
| 在职医生下拉 | `getDoctorOptions(params)` | `GET /doctors/options`（选上级/分配用） |
