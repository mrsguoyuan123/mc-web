## 六、保存（基本信息部分）

- 编辑：`updateRoleById(id, data)` → `PUT /roles/{id}`。
- 新增：`createRole(data)` → `POST /roles`；请求体含 `code / name / terminal / baseRole / dataScope / scopeJson / sortNo / description / status / permissionCodes`。
- 复制：`copyRoleById(id, { name, code })` → `POST /roles/{id}/copy`；源角色权限与配置由后端克隆。
- 保存失败：code 非 0 抛 ApiError，消息提示原因，不清空表单与已勾选项；编码唯一冲突、内置字段受限等按返回 message 展示。
