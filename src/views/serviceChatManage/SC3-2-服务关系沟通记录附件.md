# 指令 SC3-2：资料抽屉 - 服务关系 / 沟通记录 / 附件资料

> 模块定位：承接 SC3-1 抽屉容器，落地后三个只读页签。
> **接口口径：复用 patient 模块只读 GET；客服视角只读，不接关系变更、附件上传/删除。**
> 入参：`patientId` 由 `CsProfileDrawer.vue` 透传。空值口径同全局约定。

## 一、技术规范（强制）

- Vue3 `<script setup>` + Element Plus，**不要 TypeScript**；接口从 `../../api/index.js`（API 统一出口，本项目无 `@` 别名），工具从 `@/utils/index.js`。
- 附件 URL 用 `resolveFileUrl` 拼接；相对路径补 baseURL，完整 http(s) 原样返回，空值返回空串。
- 页签懒加载；分页 `page/pageSize`，`pageSize` 默认 20、上限 100。

## 二、服务关系页签（`ServiceRelationTab.vue`）

### 数据：`getPatientServiceRelationsById(id)` → `GET /patients/{id}/service-relations`

返回 `{ current, logs }`：
- `current`：当前服务关系对象（医生/主管医生/客服/陪诊师等），按设计稿「服务角色三卡」展示角色、姓名、id。
- `logs`：最近 20 条变更记录，字段 `{ id, relationType, operatorName, reason, createTime, beforeId, afterId, operatorId }`。
  - `relationType`：`CS 客服 / CAREGIVER 陪诊师 / DOCTOR 医生`，用全局 `RELATION_TYPE_TEXT`。
  - `createTime` 格式 `YYYY-MM-DD HH:mm`。
- 顶部只读提示黄条：「当前为客服只读视图，关系变更请联系管理员」。
- 角色名字典若只回 id，待联调补名；补不到显示 `MISSING_TEXT`。

## 三、沟通记录页签（`CommunicationTab.vue`）

### 数据：`getPatientCommunicationsById(id, params)` → `GET /patients/{id}/communications`

分页返回 `PageResult<CommunicationItem>`：`{ list, total, page, pageSize }`；行字段 `{ type, time, title, content, operator }`。

### 筛选与映射

- 渠道筛选 `channel`：`MESSAGE 消息 / CALL 电话`。
- **待联调**：设计稿分类「聊天 / 虚拟电话 / 智能客服 / 系统记录」与现有 `channel`（仅 MESSAGE/CALL）口径不一致；`MESSAGE` 内是否再分智能客服/系统记录、是否有 `messageType/senderType` 字段，需后端确认。确认前筛选只挂 MESSAGE/CALL 两项，其余分类置灰标注待补。
- 行展示：`time`（`YYYY-MM-DD HH:mm`）、`title`、`operator`、`content` 摘要；`type` 标签按渠道字典上色。
- 另支持 `keyword` 关键字、`from/to` 日期筛选；分页 `page/pageSize`。

## 四、附件资料页签（`AttachmentTab.vue`）

### 数据：`getPatientAttachmentsById(id, params)` → `GET /patients/{id}/attachments`

分页返回 `{ list, total, page, pageSize }`；行字段 `{ id, category, fileName, fileSize, url, uploaderRole, createTime, updateTime }`。

### 展示与操作

| 展示 | 字段 | 备注 |
|---|---|---|
| 文件名 | `fileName` | 缺失 `MISSING_TEXT` |
| 分类标签 | `category` | 枚举：检查报告/影像资料/病理资料/饮食记录/运动记录/其他 |
| 大小 | `fileSize` | 字节转 KB/MB；缺失 `-` |
| 上传角色 | `uploaderRole` | `DOCTOR/CS/CAREGIVER/PATIENT/ADMIN`，字典待联调 |
| 上传时间 | `createTime` | `YYYY-MM-DD HH:mm` |
| 预览/下载 | `url` | `resolveFileUrl(url)`；预览前端实现（图片直显，其他类型走下载） |

- 分类筛选 `category`；分页。
- 只读：不渲染上传、删除按钮；`uploaderName` 若接口未返回，待联调二次查询补名，不臆造上传人。
- 附件本体下载走拼接后的完整 URL；空 url 返回空串。

## 五、本段接口对接（复用 patient，只读 GET）

| 页签 | 函数 | 路径 / 方法 |
|---|---|---|
| 服务关系 | `getPatientServiceRelationsById(id)` | `GET /patients/{id}/service-relations` |
| 沟通记录 | `getPatientCommunicationsById(id, params)` | `GET /patients/{id}/communications` |
| 附件资料 | `getPatientAttachmentsById(id, params)` | `GET /patients/{id}/attachments` |

## 六、待联调确认

- 服务关系 `current` 内嵌角色对象真实子字段名；角色名字典来源。
- 沟通记录「智能客服/系统记录」分类对应的筛选字段与枚举；`operator` 是否回传姓名。
- 附件 `uploaderName` 是否二次查询；`uploaderRole` 中文映射；分类枚举是否需扩展。
